AI IMPOSTER PLUS ONE — UPDATED BUILD

Files: index.html, style.css, script.js, ai.js, server.js.

Run in PowerShell from this folder:
  node server.js
Then open http://localhost:3000 in your browser.

If the server needs an Anthropic API key, set ANTHROPIC_API_KEY in the same terminal before starting the server. Keep the key private and do not commit it to GitHub.

Changes in this update:
- The AI's secret word is never shown on the human secret-word screen. The screen instead says the AI is getting ready and its clue is coming.
- Added animated ambient orbs, drifting particles, a subtle custom cursor aura, animated gradient buttons, and hover effects.
